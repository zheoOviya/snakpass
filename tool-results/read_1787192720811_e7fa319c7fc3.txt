   924→   924→
   925→   925→Payment must be modeled as a state machine.

   933→   933→```

   935→   935→Instead:
   936→   936→
   937→   937→```text
   938→   938→Create order
   939→   939→→ generate internal idempotency key
   940→   940→→ create payment intent/order
   941→   941→→ gateway interaction
   942→   942→→ verify callback/webhook
   943→   943→→ persist authoritative payment state
   944→   944→→ fulfilment proceeds according to policy
   945→   945→```
   946→   946→
   947→   947→All external gateway calls must have explicit retry/idempotency strategy.
