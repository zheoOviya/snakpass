The version-based pattern would unnecessarily fail concurrent calls with 409 — but for idempotent accept, concurrent calls should BOTH succeed (the second one returning `alreadyAccepted: true`). The acceptedAt IS NULL conditional + re-fetch pattern achieves this cleanly.
